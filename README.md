# Pixcell Android App - Online Charging System

Pixcell is an Android application that allows users to track their remaining internet, SMS, and call usage. The app enables users to log in or sign up to monitor their remaining internet, SMS, and call allowances. All usage data is fetched dynamically via an API.

## Features
- User login and registration functionality.
- Track remaining internet, SMS, and call usage.
- Usage data is fetched from an API and displayed to the user.
- Simple and user-friendly interface.

## Prerequisites

To run this project locally, ensure you have the following installed:

- **Android Studio** (or any other Android development environment)
- **JDK 8** or later
- **Gradle** (for building the project)
